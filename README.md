

# Low Poly Farming Game

A 3D farming prototype developed in Unity using a tile-based farming system and low poly visuals.

---

## Features

- Tile-based farming system
- Land plowing interaction
- Planting and harvesting crops
- Inventory
- Timeline-based farming animations
- Day & night cycle with customizable day duration
- Low poly environment
- Event-driven UI updates

---

## Gameplay

- Interact with farm tiles
- Plow, plant, water, and harvest crops
- Manage inventory and tools

---

## Built With

- Unity
- C#
- Unity Timeline
